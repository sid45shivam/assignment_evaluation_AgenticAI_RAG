# Scoring Policy

## 1. Rubric first
The approved rubric is the only scoring standard. Reference material is
supporting context. A student is not penalised for using different words
from the course notes.

## 2. Evidence
- Evidence is text copied exactly from the student's submission.
- Use "..." only to skip words inside one passage. Never join text from
  different places into one quote.
- Do not paraphrase inside quote marks.
- No exact quote means no marks above 0 for that criterion.
- A criterion the student skipped: evidence is `No evidence found`, marks 0.

## 3. Citations
- Cite only chunks retrieved for this criterion, with filename and page.
- Do not say a source supports something it does not state.
- If nothing relevant is retrieved, write:
  `Context Limitation: No specific reference context available in course database`
  and score from the rubric alone, without penalising the student.

## 4. Numerical answers (carry-forward)
- Use the numerical-verification result, never your own arithmetic.
- The step where the student's error starts loses marks.
- Later steps that use the student's own wrong figure correctly keep their
  method marks. Do not penalise the same error twice.
- A result inside the verifier's tolerance counts as correct.

## 5. Choosing a mark
- Pick the band that matches what is actually present.
- Give the top of a band only if every point in that band is met.
- If the answer sits between two bands, use the lower band and set
  confidence to MEDIUM.

## 6. Alternative answers
Credit a different approach if it: answers the question, reasons logically,
uses relevant concepts, and reaches a defensible conclusion.
If the assignment says alternatives are allowed, do not penalise the student
for choosing one. Escalate to faculty only when academic judgement is needed.

## 7. Confidence
- HIGH: evidence and rubric clearly support the mark.
- MEDIUM: band edge, a valid alternative approach, or some uncertainty.
- LOW: significant judgement needed. Always escalate to faculty.

## 8. Faculty
The system proposes marks. Faculty makes the final decision.
